# App Store Connect

> 🤖 *This document was generated by an AI Agent.*

This directory contains the manifest-only `source-app-store-connect` connector.
It reads apps, customer reviews, Sales and Trends reports, finance reports, and
App Store Analytics reports from Apple's App Store Connect API.

## Usage

You can use this connector from the Airbyte Marketplace, load it through
PyAirbyte, or open the manifest in Connector Builder.

See the [connector documentation](../../../docs/integrations/sources/app-store-connect.md)
for credential setup, configuration fields, streams, and data-availability
notes.

## Local development

Build the connector image from this directory:

```bash
airbyte-cdk image build
```

Run connector commands through the resulting Docker image. For commands that
require credentials, place a development config at `secrets/config.json`.

```bash
docker run --rm airbyte/source-app-store-connect:dev spec

docker run --rm \
  --volume "$PWD/secrets:/secrets:ro" \
  airbyte/source-app-store-connect:dev \
  check --config /secrets/config.json
```

Run the mock-server tests with `uv`:

```bash
cd unit_tests
uv run pytest .
```
