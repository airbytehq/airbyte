# Connector configuration reference

When you create or update a source or destination with the [Airbyte API](/developers/api-reference/airbyte-api), the `configuration` field holds connector-specific settings: a Postgres source needs a host, port, and credentials, while a Stripe source needs an API key. Those fields come from the connector itself, so the API reference describes `configuration` as a generic object.
