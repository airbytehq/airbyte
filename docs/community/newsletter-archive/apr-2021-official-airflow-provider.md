# Official Airflow Provider

_Published April 13, 2021. [View on airbyte.com](https://airbyte.com/community/newsletter/apr-2021-official-airflow-provider)._

Here are the community news and product updates of the past week.

[![Newsletter\_10\_Airflow.png](https://airbyte.com/images/community/newsletter/bodies/2021/04/Newsletter_10_Airflow.png)](https://airflow.apache.org/docs/)

[**Airbyte becomes an official Airflow provider**](https://airflow.apache.org/docs/)

Thanks to [@marcosmarxm](https://github.com/marcosmarxm), Airbyte has been released in Airflow's last release. We're now featured as a package provider! You can now run Airbyte jobs from Airflow directly. This was the most requested feature in the last few months.

[**CHECK OUT AIRFLOW'S PACKAGES >>**](https://airflow.apache.org/docs/)

[![Change Data Capture Postgres](https://airbyte.com/images/community/newsletter/bodies/2021/04/Change-Data-Capture-Postgres.png)](https://docs.airbyte.com/platform/understanding-airbyte/cdc)

[**Change Data Capture (CDC) for Postgres!**](https://docs.airbyte.com/platform/understanding-airbyte/cdc)

Thanks to [@jrhizor](https://github.com/jrhizor) and [@cgardens](https://github.com/cgardens), we now support CDC for Postgres. This is a first step, as we will start supporting for other databases this month: MySQL, MSSQL, etc.

[**CHECK THE CDC DOCS >>**](https://docs.airbyte.com/platform/understanding-airbyte/cdc)
