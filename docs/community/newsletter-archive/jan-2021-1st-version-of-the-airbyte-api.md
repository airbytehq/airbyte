[![API\_documentation.png](https://airbyte.com/images/community/newsletter/bodies/2021/02/API_documentation.png)](https://petstore.swagger.io/?url=https://raw.githubusercontent.com/airbytehq/airbyte/master/airbyte-api/src/main/openapi/config.yaml#/)

[**Our API documentation (still in alpha)**](https://petstore.swagger.io/?url=https://raw.githubusercontent.com/airbytehq/airbyte/master/airbyte-api/src/main/openapi/config.yaml#/)

We just released the 1st version of our API docs. You can now use Airflow and Dagster to trigger Airbyte's data syncs. A note though: this API docs will evolve. You won’t lose any functionality, but you may need to update your code
