# Dremio

## Overview

The Dremio source supports Full Refresh sync of catalog metadata from a self-hosted Dremio instance. It does not replicate the rows of the tables listed in the catalog.

### Output schema

The following output stream is available from this source:

- [Catalogs](https://docs.dremio.com/software/rest-api/catalog/get-catalog/) \(Full table\)

If there are more endpoints you'd like Airbyte to support, please [create an issue.](https://github.com/airbytehq/airbyte/issues/new/choose)

### Features

| Feature                   | Supported? |
| :------------------------ | :--------- |
| Full Refresh Sync         | Yes        |
| Incremental - Append Sync | No         |
| SSL connection            | Yes        |
| Namespaces                | No         |

## Getting started

### Requirements

- A valid Dremio authentication token
- The base URL of a self-hosted Dremio instance reachable from Airbyte

### Setup guide

Connector needs a self-hosted instance of Dremio, this way you can access the Dremio REST API on which this source is based. Please refer to [Dremio Deployment Models](https://docs.dremio.com/software/deployment/deployment-models/) document, or take a look at [Dremio OSS](https://github.com/dremio/dremio-oss) for reference.

1. Set **Base URL** to the URL of your self-hosted Dremio instance, including the scheme and port if needed, such as `https://dremio.example.com:9047`. Do not include `/api/v3/catalog`; the connector appends that path.
2. Generate an authentication token following [Dremio's authentication instructions](https://docs.dremio.com/current/reference/api/#dremio-authentication-tokens).
3. Set **API Key** to the returned `token` value, without an `Authorization`, `Bearer`, or `_dremio` prefix. The connector adds the `_dremio` prefix itself.

:::warning Self-hosted Dremio only

Replace the prefilled `https://app.dremio.cloud` URL with your self-hosted instance URL. The prefilled URL is the Dremio Cloud web application, not the self-hosted REST API. Dremio Cloud uses a different, project-scoped API and is not supported by this connector.

:::

### Troubleshooting unauthorized errors

Dremio authentication tokens generated by `/apiv2/login` expire after 30 hours. If the connection check reports that the `catalogs` stream is unauthorized, generate a new token and update **API Key**. Ensure the token belongs to the instance in **Base URL** and does not already contain the `_dremio` prefix. See [Dremio API authentication](https://docs.dremio.com/current/reference/api/#authentication) for token details.

## IP allow list

If you use Airbyte Cloud and your organization restricts access to specific IPs, add the [Airbyte Cloud IP addresses](https://docs.airbyte.com/platform/operating-airbyte/ip-allowlist) to your allow list.
