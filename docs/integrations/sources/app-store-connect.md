# App Store Connect

> 🤖 *This document was generated by an AI Agent.*

The App Store Connect source replicates app metadata, customer reviews, Sales
and Trends reports, finance reports, and App Store Analytics reports from the
[App Store Connect API](https://developer.apple.com/documentation/appstoreconnectapi).

## Prerequisites

- An App Store Connect team API key. Individual API keys are not supported.
- The API key's issuer ID, key ID, and downloaded `.p8` private key.
- Your numeric vendor ID for Sales and Trends and finance reports.
- Permissions for every report family you plan to sync.
- An existing `ONGOING` or `ONE_TIME_SNAPSHOT` analytics report request for
  each app whose analytics data you want to sync. This connector reads report
  requests but does not create them.

Apple only lets you download a private key once. Store it securely after you
create the key in **Users and Access > Integrations** in App Store Connect.
Copy the complete `.p8` contents, including the `BEGIN PRIVATE KEY` and
`END PRIVATE KEY` lines, into the connector configuration.

## Configuration

| Input | Required | Description |
| --- | --- | --- |
| `iss` | Yes | Issuer ID for the App Store Connect team API key. |
| `kid` | Yes | Key ID for the App Store Connect API key. |
| `secret_key` | Yes | Complete `.p8` private key used to sign ES256 JWTs. |
| `vendorID` | Yes | Numeric vendor ID shown in App Store Connect. |
| `analytics_reports_start_date` | Yes | First analytics processing date to read, in `YYYY-MM-DD` format. Use the ongoing request creation date or a later date. |
| `reviews_start_date` | No | First customer review creation time to read, in UTC `YYYY-MM-DDTHH:MM:SSZ` format. Defaults to `2020-01-01T00:00:00Z`. |
| `sales_reports_start_date` | No | First daily Sales and Trends report date, in `YYYY-MM-DD` format. Defaults to the oldest date in Apple's 365-day retention window. |
| `subscription_event_reports_start_date` | No | Independent first date for subscription event reports, in `YYYY-MM-DD` format. |
| `subscription_event_skip_dates` | No | Dates whose unavailable or invalid subscription event archives should be skipped. |
| `finance_reports_start_date` | No | First finance report month, in `YYYY-MM` format. Defaults to the oldest month in the connector's 12-month window. |

## Data availability

- Sales and Trends daily syncs are limited to Apple's rolling 365-day window.
- Finance syncs are limited to approximately the most recent 12 months and end
  at the latest complete fiscal month.
- Analytics ongoing requests do not backfill data from before their creation.
- Apple can take one or two days to generate the first analytics reports after
  a request is created, and stops producing reports for inactive apps.
- A report stream can be empty when the API key lacks access to that report,
  the app does not produce that report type, or Apple has not published the
  requested period yet.

The connector retries rate limits and transient server errors. It signs a new
ES256 JWT with a 15-minute lifetime for App Store Connect requests. Analytics
downloads use Apple's short-lived pre-signed URL without forwarding the JWT.
